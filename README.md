## 🚀 Featured Project

### 🏛️ Civicmatch (SchemeSetu)

**Civicmatch** is a full-stack AI platform designed to match Indian citizens with eligible government schemes.

The system uses an **Explainable AI rules engine** and confidence-based recommendations to identify suitable schemes based on citizen information.

### Key Features

- 👤 Dynamic Citizen Profiling
- 🤖 Explainable AI Rules Engine
- 📊 Confidence-Based Recommendations
- 🏛️ Government Scheme Matching
- 🗄️ SQLite Database
- 📱 Responsive User Interface
